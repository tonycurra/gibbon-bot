# Security

This firmware can enable torque on a robot arm. A bug in `estop`, `raise`, or a joint clamp is a safety report, not a normal feature request.

Email [services@olivabot.com](mailto:services@olivabot.com) with the firmware stamp (`info`), the command you sent, and what the limb did. A private report is fine. A fix for a stop or a wall can be published on its own even when other work stays in a private branch.

There is no bug bounty. Research equipment, no warranty.
