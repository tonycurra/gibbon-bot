# 2026-09-09 — console + compact get

USB in, pack on, Django `:8080`. Firmware on the chip is still the previous fat-`get` build until the next flash.

## What we decided

Chip is a **text API** (USB or BLE). Gibbon-console is the brain: limits, calibrate, actuate, show **real** Feetech present @56. No IMU / INA219 / LED.

Six joints, seven motors. Shoulder = **yaw** (11) + **pitch** (12+13, physically coupled). Names: `docs/hardware/motors/names.md`. Human docs: console `/info/`.

## Firmware (this tree, **unflashed**)

`stream` no longer prints seven full lines every 180 ms. It skips still IDs and omits default zeros (`cur=0`, `turns=0`, `mode=0`, `un` when it equals `pos`, …). Host scripts parse `key=value` so old and new lines both work.

Flash when ACM0 is free: `docs/framework/espidf.md`. Same flash should include twist ESTOP if that source is already in `main.c`.
