arm

One RoArm-M3 Pro. ESP32 on the Waveshare Bus Servo Driver HAT talks ST serial-bus servos at 1 Mbps. USB and BLE are the same text pipe. The console is the brain; the chip clamps and talks to the bus. No IMU, no HAT current chip, no fake sensors. Gold bring-up dumps: hat.

3. what we can read

Only sensors are inside each Waveshare ST32xx. Present block at register 56 (15 bytes). No IMU, no force/torque cell, no HAT current chip. USB does not power the motors — pack off → all miss.

In the motor table the columns mean:

columnkindwhattq off (you turn by hand)
idlabelbus ID—
possensor12-bit magnetic encoder on the horn, 0–4095, wrapsthis is what moves
underived (ESP)pos unwrapped across turns — computed on the chip, not a sensorfollows pos
spdderived (motor)speed the servo computes from that encoderusually 0 unless you spin fast
loadderived (motor)inner PID effort, not a torque cell. our force proxyalways 0
mAsensor (estimate)winding current inside the servo. light hits often 00

tqflagtorque enable on/off0 = free / backdrive

Sensors that exist: encoder, VIN, temperature, current estimate. Everything else is a flag or a calculation from those. The motor page charts all four sensors plus load and speed. Backdrive → watch pos. Hold or a commanded fight → watch load (and mA if it leaves 0).

4. servo / wheel / step

Each motor has a mode register (33) in EEPROM. We almost always stay in servo.

modeyou commandinner loopuse here
servo (0)goal position + speed + accposition PID in the servodefault. yaw, pitch, elbow, wrist, hand
wheel (1)signed speedspeed closed-looptwist unwrap / jog only. EEPROM. always restore servo
step / multi-looprelative stepsposition, lost on power-offavoid

There is no torque-control mode. tq=1 means “hold / follow the goal.” It is not a newton-metre setpoint. We do not PWM the HAT ourselves — the servo MCU does the phase drive.

5. how we command

  1. Laptop/console sends a text line (USB or BLE).
  2. ESP32 clamps (walls, hop, pack ≥ 10.5 V) then WritePos on the bus: goal pos, speed (default 300 steps/s), acc (default 20).
  3. The servo tracks that goal with its own loop. We poll get (present @56).

Not a host PWM. Not a host PID writing position from error — that would fight the servo PID. Smoothness today = slow speed + acc, later maybe many small goals (trapezoid) still in servo mode.

6. PID — whose loop?

Classic: error = goal − measured. Effort from P (∝ error), I (sum of error), D (rate of error).

  • Inside the servo — already running in servo mode. Kp/Kd/Ki in EEPROM (who). We do not retune first.
  • Chip — supervisor: clamp, voltage, ESTOP on load/cur/miss while twist is in wheel.
  • Host — unwrap, pair 12+13, later FK. Cadence ~ USB, not kHz.

What we set without touching inner gains: goal, max speed, acc, tq on/off. Load is the effort the inner loop is applying — useful as a contact proxy while tq=1.

A laptop PID on top of the servo PID is worse than either alone. Wheel + outer P (command speed from pos error) is only a maybe for twist unwrap.

7. shoulder pitch 12+13

One joint, two motors, physically stuck together. Move the upper arm by hand and watch both positions. Header fw old means the sitting chip has no SyncWrite — console will not send raise …; hold/free stay id 12 + id 13. After flash, info fw=20260912 raise=1 and the header turns cyan: then raise to / raise hold / raise free. If they fight, STOP. Set pair (mirror − / same +) on calibration / shoulder pitch before any raise jog.

8. walls and calibrate

Find the wall by hand, tq off. On calibration, click home (this pose = 0°), then min / max at the stops. Hand: closed = 0°, open is +°. Wrap (yaw, wrist roll): pos jumps at 0/4095 while un keeps going. Shoulder pitch: set mirror − or same + on that page before test. Commanded moves check the band; they do not find it. Hand gold: open 609, close 2088. Twist: this sitting’s slack, not an old home. Host unwraps wrap joints.

EEPROM amin/amax on the chip are often 0–4095 (no wall). Our walls live on the host + firmware clamps for hand/twist.

9. stop

  • Header STOP / Escape = estop (all tq=0, twist back to servo).
  • No move on boot.
  • Do not command a joint with no wall.
  • Never jog 12 or 13 alone.
